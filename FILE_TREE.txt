HOW THE SITE IS ORGANIZED
--------------------------
- Root index.html = a generated copy of whichever theme is "live" (currently theme-d).
  Regenerate it any time with: ./switch-theme.ps1 <A|B|C|D>
- Each theme-X/ folder is self-contained: its own index.html, links.html, projects.html,
  and Projects/<name>/<page>.html, all styled to match that theme and using paths
  relative to that folder.
- Shared, non-themed resources live at the repo root and are referenced by every theme
  via relative paths ("../"): images/, assets/ (fonts, legacy main.css/project.css, JS),
  Projects/<name>/ media files (thumbnails, screenshots, videos), and Projects/Resume/
  (resume HTML + PDF — identical across all themes, never duplicated per-theme).
- The original un-suffixed Projects/<name>/<page>.html files (aurora-styled, using the
  shared assets/css/project.css) are legacy/orphaned — no theme links to them anymore,
  kept only because they still work standalone if someone has them bookmarked.

MAINTENANCE NOTES
-------------------
- Adding a new personal project: add its media to Projects/<Name>/, then create a themed
  page at theme-a/Projects/<Name>/<page>.html (and b/c/d), linking the shared media via
  "../../../Projects/<Name>/..." and the theme's own stylesheet via "../../assets/css/project.css".
  Add a tile to each theme-X/projects.html pointing at "Projects/<Name>/<page>.html" (theme-local).
- Updating the resume: edit only Projects/Resume/ — every theme already points there, no
  per-theme duplication needed.
- Switching the live theme: run ./switch-theme.ps1 <A|B|C|D> from the repo root.
