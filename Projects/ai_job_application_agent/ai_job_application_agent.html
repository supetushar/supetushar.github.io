Overview

An agentic system that automates the end-to-end job application workflow: it searches for jobs, parses job descriptions, matches them against a structured candidate profile, generates tailored application materials, and completes submission steps through browser automation.

This is an active, ongoing personal project — built to apply the same agentic-AI and retrieval patterns I use professionally to a practical, high-volume personal workflow.

How It Works

  • Job search & parsing — discovers relevant openings and extracts structured data from job descriptions.
  • Candidate matching — retrieval-augmented generation over a structured candidate profile and job data to assess fit.
  • Tailored materials — generates application materials tailored to each role.
  • Submission automation — completes submission steps through browser automation, end-to-end.

Tech Stack

Built with LangGraph for agent orchestration, retrieval-augmented generation (RAG) over candidate and job data, tool-calling and MCP integration, a FastAPI / PostgreSQL backend, and Playwright for browser automation.
